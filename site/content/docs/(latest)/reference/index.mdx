Session kit publishes one entry point for each part of the package. This page
lists them, with what each one exports. Each entry point's page documents its
exports, with their options and types.

## Entry points

API.

## Bundle size

The package is tree-shakeable, so a bundle holds only what you import. An
entry point you don't import adds nothing.

## Errors

Errors from Session kit's own logic are `AuthError`s. In `./effect` and
`./effetch`, Effects fail with `AuthFailure`, which carries the same code.
See [Error codes](/docs/reference/error-codes) for every `AuthErrorCode`.

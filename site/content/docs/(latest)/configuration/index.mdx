title: Configuring the client
description: Every option createAuth takes, with a page for each part of the client you can configure.
---

`createAuth` takes three required options and five optional ones:

| Option    | Required | What it sets                                                                                                    |
| --------- | -------- | --------------------------------------------------------------------------------------------------------------- |
| `name`    | Yes      | The storage namespace: letters, digits, `_` or `-`. Keeps two apps on one origin apart.                         |
| `user`    | Yes      | A [user schema](/docs/configuration/user-schemas), or [`fromAccessToken`](/docs/client/users-from-tokens).      |
| `storage` | Yes      | [Where the session is saved](/docs/configuration/storage).                                                      |
| `refresh` | No       | [How expired access is replaced](/docs/configuration/refresh). Without it, an expired token signs the user out. |
| `revoke`  | No       | [Revokes the ended tokens](/docs/client/signing-in-and-out) on your backend after a sign-out.                   |
| `maxAge`  | No       | How long a saved session is restored, in seconds. Default: 30 days, renewed on each save.                       |
| `debug`   | No       | [Reports what the client does](/docs/configuration/debugging). Default: off.                                    |
| `locking` | No       | [Restores a saved session as `locked`](/docs/client/locking), for native apps. Default: off.                    |

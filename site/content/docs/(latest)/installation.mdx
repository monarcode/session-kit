Install Session kit, a schema library, and the packages your setup needs, then
follow the guide for that setup.

To install the package, run the following command:

```npm
npm install @monarcode/session-kit
```

Alpha releases are published to the `latest` distribution tag and may change
the public API, so pin an exact version and read the
[release notes](https://github.com/monarcode/session-kit/blob/main/CHANGELOG.md)
before upgrading.

Session kit checks each user against a schema from any
[Standard Schema](https://standardschema.dev) library. The examples use Zod.
To install it, run the following command:

```npm
npm install zod
```

Then install React, and the router or framework your setup uses.
[Compatibility](/docs/reference/compatibility) lists every optional peer
dependency and the versions it supports.

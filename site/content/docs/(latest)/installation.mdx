Your app needs Session kit, a schema library to describe your users, and the
packages your setup already uses, such as React and your router. Install the
first two here, then follow the guide for your setup.

To install Session kit, run the following command:

```npm
npm install @monarcode/session-kit
```

Release candidates are published to the `latest` distribution tag. The API
is frozen for 0.1: later 0.1 releases only add to it. Pin an exact version,
and read the
[release notes](https://github.com/monarcode/session-kit/blob/main/CHANGELOG.md)
before upgrading.

Session kit checks each user against a schema from any
[Standard Schema](https://standardschema.dev) library. The examples use Zod.
To install it, run the following command:

```npm
npm install zod
```

Then install React, and the router or framework your setup uses. Each is an
optional peer dependency, so install only the ones your setup imports.

Session kit needs TypeScript 5.4 or newer, and Effect asks for 5.9 or newer.
[Compatibility](/docs/reference/compatibility) lists the runtimes and the
peer dependency versions it supports.

## Pick your setup

Find your setup in the following table. Each row names the entry point for
your router or framework, and the guide to follow. All but the first also
have a runnable app in
[`examples/`](https://github.com/monarcode/session-kit/tree/main/examples)
that signs in against DummyJSON's public test API:

| TanStack Router                            | `@monarcode/session-kit/tanstack-router`     | [TanStack Router](/docs/setups/tanstack-router)                            | [`tanstack-router`](https://github.com/monarcode/session-kit/tree/main/examples/tanstack-router)                                                                                                                               |

Every setup also imports its client from `@monarcode/session-kit`:
`createAuth`, or with server rendering, `createMirrorAuth`. Server-rendered
setups import more on the server, and each guide shows what.
[Entry points](/docs/reference) lists every import path.

Two guides apply to more than one setup:

- [Server sessions](/docs/server-rendering/server-sessions) covers what the
  three server-rendered setups share.
- [Effect and effetch](/docs/effect) works with any setup.
